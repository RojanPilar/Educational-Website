# Rojan Educational — Interactive EdTech Showcase Platform

A beautiful, responsive digital resource directory and educational landing platform designed from scratch featuring clean, soft pastel layout constraints to support global family resource downloads.

## Tech Stack
* **Core Stack:** Vanilla JavaScript, HTML5, CSS3
* **Content Delivery Performance:** Fastly CDN, Varnish Caching
* **Typography Engine:** Google Font API
* **Deployment Platform:** GitHub Pages

## Key Features Built
* **Fluid Geometry Visuals:** Custom landing sections utilizing accessible color styling, organic background forms, and rigid grid layouts.
* **Interactive Resource Row:** Touch-responsive academic category blocks and dynamic download buttons engineered to fetch digital workbooks cleanly.
* **Query Data Container:** A complete client-facing contact and inquiry block built with real-time UI validation fields and localized state success notifications.
* **Lightweight Asset Deployment:** Fully optimized structural padding configurations to enforce immediate rendering across all desktop and mobile viewport widths.
